# Fitness

A single-user app for vertical jump, athleticism and upper body training: nutrition, an exercise directory, AI-generated workouts and progress tracking.

## Getting started

The guide lives in the app, at `/guide`, and Today links to it from its header.
On a fresh install Today also shows a getting-started card with the next setup step, until setup is done or the card is hidden.
The guide covers the one-time setup, the daily loop, the weekly loop and how to review what the AI proposes.

## Development

`AGENTS.md` has the commands, the layout and the conventions that are easy to get wrong.
